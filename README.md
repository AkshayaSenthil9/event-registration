# Campus Connect 2026 – Event Registration Website

A responsive front-end Event Registration Website created for a college skill-development activity.

## Files
- `index.html` – website structure and content
- `style.css` – responsive styling
- `script.js` – form validation and localStorage demo data

## Run
Open `index.html` in any modern web browser.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose the `main` branch and `/ (root)`.
5. Save and wait for deployment.
6. Your public URL will follow this pattern:
   `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

## Important
The registration records are stored only in the visitor's browser using localStorage. This is a demonstration website and does not send registrations to a real server or database.
